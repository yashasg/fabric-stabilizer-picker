# fabric-stabilizer-picker

## App icon

A minimalistic embroidery app icon lives in the repo root:

- [`icon.png`](icon.png) — 1024×1024 icon

It is based directly on the design prototype (linen fabric square, dashed
running-stitch border, wooden hoop, brass tension screw, olive leaf sprigs,
terracotta berry knots, and a brass needle with thread) with the embroidered
"e" lettermark removed, leaving the center as plain woven fabric.
