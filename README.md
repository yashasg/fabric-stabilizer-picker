# fabric-stabilizer-picker

## App icon

A minimalistic embroidery app icon lives in the repo root:

- [`icon.svg`](icon.svg) — scalable vector source
- [`icon.png`](icon.png) — 1024×1024 export

It keeps the vibe of the attached design prototype (linen fabric square, dashed
running-stitch border, wooden hoop, brass tension screw, and a needle with thread)
but replaces the "e" lettermark with a simple floral spray, leaning into the
**Madder Clay** (`#A6442E`) accent color.
